# The Crea Lab · installation

Ces fichiers installent **The Crea Lab**, le kit de montage de Reels et Shorts de Laura Hurtado (@lacreacom).

Le kit lui-même n'est pas ici : il est réservé aux clientes, dans leur espace The Crea Lab. Télécharge d'abord `the-crea-lab.zip` dans la leçon « Installation », puis colle la commande.

**Mac**, dans le Terminal :

```bash
curl -fsSL https://raw.githubusercontent.com/Lacreacom/the-crea-lab-installation/main/install.sh | bash
```

**PC**, dans PowerShell :

```powershell
irm https://raw.githubusercontent.com/Lacreacom/the-crea-lab-installation/main/install.ps1 | iex
```
