# Questions déjà résolues (Schoolmaker et Lab SOS)

Julie cherche ici AVANT de répondre. Chaque « ## » est une question déjà posée par une cliente dans la communauté Schoolmaker de The Crea Lab ou au Lab SOS, puis ce qui a vraiment réglé le problème.
Jamais de prénom de cliente ici. Mots-clés en fin de bloc pour la recherche.

## Le studio ne s'ouvre plus (page d'erreur, onglet vide)
Ce qui a marché : repasser par Claude.
1. Ouvre l'application Claude, onglet « Code », dossier « The Crea Lab ».
2. Ouvre une discussion et écris « Ouvre mon studio » (ou « /lab »).
Si ça recommence, refais pareil : c'est normal.
Si le studio refuse plusieurs fois de suite : relance la commande d'installation du tuto (tout ce qui est déjà installé est gardé).
Mots-clés : studio ouvre pas, page erreur, localhost, ne s'affiche pas, plus accès

## Je peux garder mon studio dans mes favoris ?
Le studio tourne sur ton ordinateur et c'est Claude qui l'allume. Quand tu fermes Claude ou éteins ton ordi, il s'éteint aussi : un favori seul ne peut pas le rouvrir.
Ce qui marche : à chaque fois, app Claude → onglet « Code » → dossier « The Crea Lab » → « Ouvre mon studio ».
Mots-clés : favori, marque-page, raccourci, signet, ouvrir sans Claude

## J'ai fait la mise à jour mais le bandeau rose reste
Le studio ouvert tourne encore avec l'ancienne version. Ce qui a marché :
1. Ferme l'onglet du studio, puis quitte complètement l'application Claude (Mac : clic droit sur l'icône → « Quitter » ; PC : ferme-la aussi dans la barre des tâches).
2. Rouvre Claude, onglet « Code », dossier « The Crea Lab ».
3. Écris « Ouvre mon studio ».
Toujours là : envoie une capture du studio et du message final de la mise à jour.
Tes vidéos, ta marque, tes scripts et ta clé ne bougent pas.
Mots-clés : mise à jour, bandeau rose, update, toujours l'ancienne version, installé

## Je ne trouve pas la leçon « Installation » pour la mise à jour / la mise à jour ne passe pas
Ce qui a marché : réessayer calmement. Dans ton espace The Crea Lab sur Schoolmaker, leçon « Installation du kit », retélécharge le kit (le fichier the-crea-lab.zip, environ 13 Mo), laisse-le dans Téléchargements, puis relance la même commande que la première fois. Dans les dernières versions, tu peux aussi cliquer sur « Mettre à jour » dans « ⚙ Réglages » du studio.
Mots-clés : mise à jour, leçon installation, introuvable, zip

## Il n'y a pas « Musique » dans l'onglet Montage (ni le bouton « 🎧 Mes musiques »)
Ton studio n'a pas encore la nouvelle version : la mise à jour ne s'est pas faite jusqu'au bout.
Ce qui a marché :
1. Sur Schoolmaker, leçon « Installation du kit », retélécharge le kit The Crea Lab (environ 13 Mo).
2. Ouvre Claude dans ton dossier The Crea Lab et écris : « Mets à jour mon kit The Crea Lab toi-même avec le zip le plus récent de mes Téléchargements, sans toucher à mes vidéos, ma marque, mes projets, mes scripts ni mes réglages. Puis relance le studio et dis-moi ma version. »
3. Rouvre le studio : « Musique » est dans l'onglet « Montage ».
Mots-clés : musique introuvable, pas de musique, onglet montage, mes musiques, ancienne version

## Quel abonnement ElevenLabs prendre ? Le Starter suffit ?
Pas besoin d'abonnement : le compte gratuit suffit, mais il faut acheter des crédits en plus. Ce sont eux qui transcrivent tes vidéos et créent tes musiques (sur certains comptes, la musique demande des crédits même quand les sous-titres marchent sans). Laura le montre dans la vidéo « Crée ta clé ElevenLabs ».
Ta clé, tu la colles toi-même dans « ⚙ Réglages » du studio. Ne l'envoie à personne.
Côté Claude : un abonnement payant, Pro minimum (environ 20 CHF par mois), pas la version gratuite.
Mots-clés : elevenlabs, abonnement, starter, crédits, clé, payer, prix, claude pro

## Je dois ouvrir une nouvelle discussion pour chaque script ?
Oui : une nouvelle discussion dans le dossier The Crea Lab pour chaque moment (idées et script avec LOU, puis une nouvelle pour le montage). Rester dans la même discussion use plus vite ton abonnement Claude. Rien ne se perd : tout est rangé dans tes dossiers.
Mots-clés : nouvelle discussion, conversation, script, abonnement se vide, tokens, limite

## J'ai trop de discussions dans Claude : je les supprime ou je les archive ?
Les deux sont sans risque : tout ce que The Crea Lab crée (scripts, voix, identité, vidéos, légendes) est dans tes dossiers sur ton ordinateur, pas dans la discussion. Archiver est le plus rassurant (tu peux la retrouver). Avant de supprimer, vérifie que tu n'es pas au milieu d'un montage.
Mots-clés : supprimer, archiver, conversations, ménage, discussions

## J'ai mes scripts et mes légendes dans Notion : je connecte Notion ou je copie-colle ?
Les deux marchent.
- Copier-coller (le plus léger) : dans une nouvelle discussion Claude, écris « Mets ce script dans mes scripts : » puis colle ton script, et « Et voici sa légende : » puis colle ta légende. Le script apparaît dans ton studio d'enregistrement. Après le montage : « Mets ma légende avec ma vidéo [titre] » : elle se range dans l'onglet « Hook et outro ».
- Connecter Notion (un peu plus de Claude utilisé, mais plus de temps gagné) : dans Claude, Paramètres → Connecteurs → Notion. Puis demande à Claude de lire ton calendrier éditorial : il met tes scripts dans The Crea Lab et ajoute tes contenus à ton calendrier Notion. Tuto vidéo de Laura : https://www.tella.tv/video/eleyess-video-bsbi3ggu
Mots-clés : notion, calendrier éditorial, scripts, légendes, copier coller, connecteur

## Mes vidéos sans parole (massage, gestes) : le studio coupe les moments inutiles ?
Le studio se guide avec la voix : sans paroles, il ne sait pas quoi garder. Ce qui a marché :
1. Filme-toi sans te soucier de la longueur.
2. Range la vidéo dans ton dossier The Crea Lab → B-roll, avec un nom clair (par exemple massage-epaules.mp4).
3. Dans une nouvelle discussion Claude : « Dans B-roll, ma vidéo massage-epaules : coupe les moments où je ne masse pas, mets une musique douce et le texte … Range la vidéo finie dans mon dossier Reels. » Tu peux donner les minutes à garder (« de 0:12 à 0:45 »).
4. Retouches dans la même discussion (« le texte plus gros », « une autre musique »).
La vidéo finie est dans Reels. Elle n'apparaît pas dans le studio (il ne montre que les vidéos où tu parles). Pour expliquer tes gestes avec ta voix : le bouton « 🎙 Voix off » du studio d'enregistrement.
Mots-clés : sans parole, sans voix, massage, gestes, couper, B-roll, vidéo muette

## Une vidéo est dans « Posté » et l'autre dans « Programmé » : pourquoi ?
C'est normal. « Programmé » : les vidéos qui attendent leur date (elles partent toutes seules via Metricool). « Posté » : celles dont la date est passée, le studio les y déplace tout seul. Pour vérifier, regarde le planning de Metricool.
Mots-clés : posté, programmé, colonnes, metricool, publication, différence

## Comment publier un réel d'essai (trial reel) ?
Pour l'instant, un réel d'essai se publie depuis l'application Instagram, pas depuis Metricool :
1. Exporte ta vidéo depuis le studio (ou prends le fichier dans ton dossier Reels).
2. Mets-la sur ton téléphone, crée un nouveau Reel dans Instagram.
3. À l'écran de publication, active l'option « Essai ».
4. Publie, puis regarde les statistiques avant de la partager à tout le monde.
Tes autres posts se programment toujours sur Metricool.
Mots-clés : réel d'essai, trial reel, essai, instagram, metricool

## PowerShell ne reconnaît pas le code que Claude me donne (installation PC)
Ce qui a marché :
1. Ferme PowerShell. Rouvre-le normalement (touche Windows, écris PowerShell, « Windows PowerShell »), surtout PAS « Exécuter en tant qu'administrateur ».
2. Recolle la commande PC de ta leçon, Entrée. Ce qui est installé est gardé.
3. À l'étape 5/5, connecte-toi, clique sur « Autoriser », copie le code tout de suite et colle-le dans PowerShell, Entrée. C'est un nouveau code : l'ancien ne marche plus.
4. Attends « C'est installé ! » en vert. Une ligne rouge : envoie une capture.
Mots-clés : powershell, code, autoriser, installation pc, windows, connexion claude

## Le studio dit « Connecte-toi une fois à Claude » alors que Claude marche (PC)
Ce qui a aidé : reconnecter Claude à la main.
1. Menu Démarrer → tape PowerShell → ouvre-le.
2. Colle : & "$env:USERPROFILE\.local\bin\claude.exe" auth login → Entrée. Connecte-toi avec le compte de ton abonnement Claude, clique sur « Autoriser » (si on te demande un code, colle-le, Entrée).
3. Puis colle : & "$env:USERPROFILE\.local\bin\claude.exe" auth status → tu dois voir "loggedIn": true.
4. Retourne dans le studio et renvoie tes retours.
Sur Mac, plus simple : « ⚙ Réglages » → « Me connecter à Claude ».
Toujours bloqué : capture d'écran à Laura.
Mots-clés : connecte-toi, connexion claude, me connecter, login, retours ne partent pas

## Le téléchargement échoue dans PowerShell (wifi pourtant bon)
Le kit est souvent déjà installé : seul le téléchargement des outils de montage bloque. Ce qui a marché :
1. Coupe ton VPN si tu en as un ; sur un ordinateur de travail, essaie depuis ton réseau perso.
2. Mets ton antivirus en pause pendant l'installation seulement, puis réactive-le.
3. Ferme PowerShell, rouvre-le et relance la même commande : elle reprend là où elle s'était arrêtée.
4. Test utile : le partage de connexion de ton téléphone.
Souvent, réessayer un peu plus tard suffit (le site était momentanément indisponible).
Mots-clés : téléchargement a échoué, wifi, internet, powershell, antivirus, vpn
